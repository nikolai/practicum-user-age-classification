# Модель-классификатор мультиклассовой классификации для предсказания возраста пользователей рекламного сервиса

## Описание

Ключевые слова: мультиклассовая классификация


## Требования

- **Python**: 3.11 или выше
- **ОС**: Linux, macOS или Windows (с WSL)

## Установка и запуск

#### Для Fish shell:

```fish
fish start.fish
```

#### Для Bash/Zsh:

```bash
./start.sh
```
